 Credit Card Fraud Detection

This project uses machine learning models to detect fraudulent credit card transactions. The goal is to accurately classify transactions as fraudulent or legitimate based on historical data.

## 📊 Features

- Data preprocessing and exploration
- Model training (e.g., Logistic Regression, Random Forest, etc.)
- Performance evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - AUC-ROC
- Visualization of results and metrics

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Libraries:
  - pandas
  - numpy
  - scikit-learn
  - matplotlib / seaborn
  - joblib (optional, for saving models)
